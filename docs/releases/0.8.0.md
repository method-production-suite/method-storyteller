# Method Storyteller 0.8.0

The editor shows the page as it prints: lines break where they print, styles show without
their marks, and a speech that runs past the page carries on to the next sheet.

## The page as it prints

- **Lines break where they print.** The editor now lays out the script itself, with the same
  rules as the printed page, so what you see on screen is what the page holds.
- **Styles without the marks.** Bold, italic and underline show as styles, with no asterisks or
  underscores around them. **View > Show Formatting Marks** brings the marks back, faint, for
  anyone who types them by hand. A `*` or `_` you type stays that character.
- **Page view carries a split speech on.** When the page breaks inside a speech or a long
  paragraph, the rest starts at the top of the next sheet, with (MORE) and the continued name
  shown faint where they print.
- **Capitals by display.** In a multi-camera script, action keeps the casing you type and is
  shown and printed in capitals. Turn the setting off and your casing is still there.
- **Double-spaced dialogue looks double-spaced** on screen, as it prints.

## Safer updates

- **An update must be signed as this app is.** On a Mac, a downloaded update is installed only
  if its code signature matches the copy you are running.
- **No going backwards.** A version older than one the app has already accepted is refused.
- **Updates that ask for an administrator's password** now leave the app owned by the system,
  as it was installed.
- **Damaged files are refused cleanly.** Every kind of file the app opens was tried in
  thousands of damaged forms; each one opens or says why.

## Fixed

- **A note on the title page** is saved to `.fdx` as a note, so it no longer prints in other
  apps, and it comes back when the file is opened again.

## For developers

- The control channel (`--control`) asks for the token each launch prints.

## Not there yet

- Pages locked in an `.fdx` file are kept and saved back, but print as unlocked until their
  positions are read reliably.
- Scene CONTINUED at page breaks is not offered yet.
- On Windows and Linux, download each new version from the website.
