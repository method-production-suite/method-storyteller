# Method Storyteller 0.5.0

Your script in one file of its own, scenes with titles and colours, a table of who speaks,
spelling in US or UK English, and nothing lost when the app closes unexpectedly. This release also brings a
security fix for update checks.

## One file for your script

- **New scripts save as a `.mstory` package:** one file holding the script as Open Screenplay
  Format, with room beside it for production details. On a Mac it has its own icon in the
  Finder. Any unzip tool opens it.
- **File > Save New Scripts as…** still offers plain Open Screenplay Format and Fountain.

## Find your way round

- **Scene titles, summaries and colours.** Right-click a scene in the navigator and choose
  Scene Properties…. The title shows in the navigator, the colour marks the row, and the summary
  appears when you point at the scene. They come in from `.fdx` files and go back out to them.
- **File > Close (⌘W)** closes the script and leaves an empty one. **File > Open Recent** lists
  the last ten scripts you had open.
- **Production > Characters** lists everyone who speaks, with their speeches, scenes, words and
  first scene. Click a name to go to their first line.

## Spelling your way

- **US or UK English** in Edit > US English Spelling and UK English Spelling. The first time you
  open this version, it chooses from your region, including when you update.

## Nothing lost

- **Unsaved changes come back.** If the app closes before you save, the next launch offers the
  changes: open the copy, throw it away, or decide later.

## Fixed

- **Update checks use up-to-date certificate checks**, closing two security advisories in the
  library that verifies the update server.

## Before you update

- Scripts saved as `.mstory` open only in this version and later.
- If you had set new scripts to save as Open Screenplay Format, they now save as `.mstory`
  packages. File > Save New Scripts as Open Screenplay Format sets it back.

## Not there yet

- No revision mode, printing or side-by-side editing of dual dialogue yet.
- On Windows and Linux, download each new version from the website.
